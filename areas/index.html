Plumbing code in Cheshire and nearby towns

Plumbing work in Connecticut follows the 2022 State Building Code, which adopts the 2021 International Plumbing Code (IPC). Each town runs its own permit office, so a job in Meriden or Wallingford is checked with that town and not with Cheshire.
